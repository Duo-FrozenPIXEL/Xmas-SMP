Grundidee:
Erstellung eines Plugins  das für ein Minecraft Server ist.
In den Versionen 1.21.11 bis 26.3 Java  für Paper , Forge und Fabric.

Das Plugin soll 5 magische Crystalle haben und eine Kopie des (Bliss Youtuber SMP) Plugins sein.
Es soll Feuer, Wind, Erde, Schatten und Natur geben

Du hast im Ordner schon ein pack mit den original Texturen des Bliss SMP Plugins.
schau dir an wie das Plugin normalerweiße funktioniert(Foren) und überleg dir welche Texturen aus dem Ordner für die Sachen möglich sind.
Da die Kräfte etwas anders als im Originl sind kannst du dir für die  schon oben gennanten Klassen Feuer, Wind, Erde, Schatten und Natur die farblich corenspondierenden Crystalle aussuchen. Feuer = Fire gem texturen. Wind = Puff gem texturen.
Benutze auch das Breaking Prisitin  system, das gem auf level system und den gem trader aus dem original
